# Building a Minimalist Academic Portfolio

This website is designed with a "content-first" philosophy, inspired by minimalist researchers like Andrej Karpathy. The goal is to provide a distraction-free experience for recruiters and academic peers.

## Tech Stack
- **React + Vite:** For speed and modern developer experience.
- **Vanilla CSS:** No heavy UI frameworks.
- **Markdown:** Automating content generation.

The centered layout and carefully chosen typography ensure maximum readability.
